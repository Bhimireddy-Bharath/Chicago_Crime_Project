About

Project and data overview

Chicago Crime Intelligence

A simple web-based dashboard for exploring Chicago crime data through visual analysis and database operations.

Purpose

The application provides a clear view of crime patterns, crime intensity, community-level analysis and arrest-related results while allowing records to be managed through REST API endpoints.

Data Overview

Dataset: Chicago Crime Dataset

Database: SQLite

Data focus: Crime records and related crime attributes

Analysis areas: Time, crime category, community and arrests

Operations: Create, Read, Update and Delete

Technology Used

Backend: Flask

API: REST API

Database: SQLite

Frontend: HTML, CSS and JavaScript

Visuals: Existing analysis graph images
